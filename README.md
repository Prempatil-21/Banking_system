# Banking System - Java

A simple console-based Banking System developed using Java.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check balance
- Display account details
- Take user input using Scanner

## Concepts Used

- Interface
- Abstraction
- Encapsulation
- Polymorphism
- Constructors
- Getters and Setters
- Method Overriding
- `toString()` method
- Scanner
- Conditional statements
- Switch case
- Do-while loop
